# forum-and-chat
"Egy PHP és JavaScript alapú, Civitai-ihlette AI-image platform fórummal és chat funkcióval (asztali nézetre optimalizálva)."

Bővebben:
Fórum és Chat Rendszer (PHP & JavaScript)
Élő demó: https://fera.site.je/
A projekt háttere: Ez a moduláris fórum és chat motor eredetileg egy összetettebb egyedi webes alkalmazás részeként készült. Ebből a korábbi projektből emeltem ki a saját magam által tervezett és megvalósított közösségi funkciókat egy önálló, átlátható referenciacsomagként.
Főbb funkciók:
Fórum témakörök, hozzászólások és jogosultságkezelés
Valós idejű / AJAX alapú csevegőmotor
SQL adatbázis-struktúra és beépített biztonsági szűrések
Élő működő referencia: https://fera.site.je/
